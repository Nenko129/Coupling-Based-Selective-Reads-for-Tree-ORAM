# Third-party provenance

Source papers are cited by metadata/hash in historical evidence. Their downloaded
PDFs and extracted full texts are not intentionally redistributed as literature
attachments in this public package.

Public trace inputs: UMass Trace Repository; HP, IBM and Storage Performance
Council. Source: https://traces.cs.umass.edu/docs/traces/storage/
The original download receipt records the repository's CC BY 4.0 statement
(unless otherwise specified) and the requirement to preserve SPC documentation
copyright notices. Original archives/documentation are obtained separately using
the included URL-and-SHA256 downloader; transformed experiment windows are
included with that attribution and their transformation code.

Preserved source files retain their own notices. No downloaded package manager
dependencies, TeX distribution, system executables, or third-party ORAM paper PDFs
are included as build dependencies. `provenance/SOC3_received.zip` inside the
workspace is original project evidence, not an external software dependency.
