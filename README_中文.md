# r8.6 投稿实验材料

本目录可整体作为 GitHub 仓库内容上传。英文 README 是审稿人的入口。
论文正文未修改，也尚未添加未确定的公开链接。

- `paper_data/data`：当前论文实际使用的 16 张 CSV 表及审计证据索引。
- `workspace`：实验源码、正式/预试验配置、输入、原始结果、失败记录、数值网格与证明审计材料。
- `docs/EVIDENCE_MAP.md`：论文主张与原始证据的对应关系。
- `tools/reproduce.py`：统一校验、轻量重放、统计复算及核心审计入口。
- `provenance`：来源、排除项和本次实际验证记录。

目录中保留了原来中文路径，以免破坏源码哈希和相对依赖。
Windows 建议解压到较短路径。复现命令见英文 README；输出要求放在仓库外的新目录，原始结果不会被覆盖。

旧研究日志和未获准入的探索性机制仍保留，不应当作正式组合实验结论。
第三方论文全文、下载缓存、运行环境及重复压缩包已排除；公开 trace 的原始下载地址和哈希保留，已处理的实验窗口随包提供。

本轮没有重新运行全部大型实验或完整数值内核；实际验证范围见 validation_summary.json。
软件许可证尚未替作者选择；发布时可按团队决定添加许可证。
收到公开仓库链接后，再在主文和补充材料中加入一致的代码/数据可用性声明。
