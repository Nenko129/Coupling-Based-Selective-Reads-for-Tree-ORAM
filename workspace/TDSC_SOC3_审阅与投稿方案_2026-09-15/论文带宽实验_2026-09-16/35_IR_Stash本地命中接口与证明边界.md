# IR-Stash：双索引后端、数据本地命中与固定时隙接口

2026-09-16。新增实现与正在运行的 raw/compressed IR、AB、Core 实验分离。本文件记录功能进展，不向论文性能表加入新的百分比。

后续转录审计已找到当前“本地跳过＋独立均匀dummy”规则的小域反例，见39号文档。下文的功能不变量不提供安全准入；新本地跳过版本的论文性能主张暂缓，待完成修复与证明。

## 实现范围

`src/ir_stash.py` 实现 Path/Deferred/SDE 的双索引：按地址散列的组相联索引，以及逻辑桶到描述符的 TT。payload 的唯一后端表示仍在已计费的可信树顶缓存；新增索引只保存描述符。索引使用 MD5(address) 确定组，作为公开查找函数，不作为密码安全原语。树顶回填遇到满组时跳过候选，继续考察其他候选。

F-Stash 与 S-Stash 命中直接返回；写命中保持 uid 和叶标签。S-Stash 写重新加密、重排该逻辑桶，保持 gamma，增加 w/v；可信边界子树根支持仅在本地重算认证根。当前仅支持非 Ring 后端，count/used 均为零，不把此实现泛化为 Ring 的消费语义。

`src/ir_stash_frontend.py` 将**数据块**命中检查接到 raw 递归位置表之前。F 命中在两种对照中都能跳过位置表；S 命中在双索引模式下直接跳过，在 dedicated-top 对照中先取得叶标签。查询父 map 本身可能提交多个递归 Transfer，因此查到数据叶之后再次探测；只有真正需要远端数据 Transfer 才更新数据叶。原来的 `_reserve_staged` 不能直接用于这一查询，因为它会先行 remap。

位置表块仍使用既有 exclusive PLB 和 Transfer，不支持所有递归 map 的原生 S-Stash 直接访问，也未接入压缩计数重置。不能将本阶段命名为“完整原生 IR-ORAM 复现”。

`src/ir_stash_controller.py` 保持每个公共时隙恰好一个 Transfer：先完成有限个本地前台步骤，再执行一个所需远端步骤；若只完成本地工作，则由 DWB 或 dummy 填充。本地 DWB 写回只有在串行提交成功后才将 LLC 行标记为 clean。

## 完成态正确性论证

设逻辑投影为每个地址的 `(uid, leaf, payload, owner)`，owner 属于 F-Stash、某个逻辑桶或 PLB。LLC 是 inclusive 副本，dirty 标记决定应用的最新 payload。可信状态包括索引、缓存、认证根、边界根、位置表和控制器状态；远端对象不可信。以下论证假定初始状态满足不变量、单线程执行以及失败后永久停止。

1. **双索引一致性。** 每个树顶 live 描述符在地址索引和 TT 中各有一个对应项。写前先根据全部被替换桶计算新索引，检查地址唯一和每组容量；远端认证写 ACK 通过后才安装新索引。判断冲突时排除全部被替换桶的旧表项，因此不会把即将回收的旧表项重复计费。实际被选中 uid 从候选池移除，未选中者仍留在 F-Stash，保持唯一所有权。
2. **F 命中。** 读返回当前 payload；写只替换同一记录的 payload。uid、leaf、位置表、出生/删除计数、t/g 和远端状态均不变。
3. **S 命中。** 先验证缓存桶及由边界根重算的全局根，再解密 header/payload 并核对索引。读不改桶；写保留该桶的记录集合、uid/leaf 和 gamma，使用递增 w/v 重新序列化并加密全部槽位，然后安装桶、索引与可信根。完成态的逻辑变化恰好是目标 payload 更新；其他记录仅物理槽位可能改变。
4. **数据位置表一致性。** 初次本地命中完全不查父 map。初次未命中时，父 map 的递归加载按旧协议提交，数据项尚未更新。随后若命中，保留原数据项；否则生成新叶并在无 yield 的区间中完成数据替换。任何异常将前端和后端一起置为 fail-stop，不能以部分更新的 map 继续执行。
5. **控制器与终止。** 每个零 Transfer 前台步骤完成一个 dirty victim 写回或一个应用请求。有限队列下，本地处理循环终止。每个 tick 最终执行一个远端 Transfer；已有 LLC 状态变迁和 DWB 版本检查维持串行读写语义。该接口不接受另一个并行的 StagedWriteback 会话。
6. **随机数与认证顺序。** 本地读不重映射，也不提交远端请求；F 写不产生后端新版本。S 写使用同一对象加密接口及递增写版本，保持放置 gamma，不能回滚重用版本。远端写失败时新索引、可信根和边界根不提交；服务器可能已收到部分变化，但后续永久拒绝。这里未提供崩溃恢复或重试协议。

这些性质说明完成态和串行存储语义相符。它们不等价于完整自适应 ORAM 安全证明。

## transcript 与容量证明尚需的条件

单个本地操作对远端输出为空；固定公共时隙只消除了“是否发出这个时隙”的差别。未来哪些路径被访问、哪些数据生成新 uid、哪些候选因组冲突留在 stash，仍依赖私有放置状态。不能仅从空 transcript 推出整个交互可模拟。

既有固定 birth/retirement 历史的 Poisson 归约不能直接复用：本地命中不 remap，改变了版本寿命；组冲突改变 canonical packing。需要为这种自适应状态过程构造新的模拟与支配过程，或明确采用不含这些优化的受限变体。本文件不声称已有容量证书覆盖此代码。

## 对带宽结论的直接约束

在相同公开窗口 W、初始维护相位、几何和固定消息格式下，若 Path/Deferred 每个公共时隙的字节数只由这些公开量决定，则

`B(W) = Σ_{t=1..W} cost(t, geometry)`。

将有用前台 Transfer 改成本地命中，再用 dummy 填充，并不会仅凭命中本身减少这一总字节数。它可腾出处理其他请求或后台工作的机会，但本项目暂不测实际加速比。SDE 的 selective 路径长度还与叶标签、phase 有关，需对真实执行逐项计费，不能套用“原通信量 × 未命中率”。

## 内存与后续接入

新增记录的规范字段合计 38 字节（address/uid/leaf/bucket/slot），不含实际字典、双索引指针及 allocator 开销。边界根为每个缓存分界节点 64 字节；真实峰值还包括解密记录、重写缓冲和认证 scratch。当前 dedicated 对照保留相同测试索引，不能当作原论文 SRAM 面积模型。

下一步接入所有 map 的本地命中时，必须同时处理 PLB 唯一所有权、parked leaf 和逐层父项更新；压缩 map 还涉及 pending reset 的提交边界。该工作与新的自适应安全/容量论证均尚未完成。正在运行的旧实验及其结果不受本文件新增接口影响。
