# 论文带宽实验与证据包

本目录从 2026-09-16 开始执行，是持续推进中的实验工作目录。**未完成，不是最终投稿证据包。** 原 SOC3 和此前研究包保持冻结。

目标：按论文大纲，完成 Path/Ring 与 selective 构造的核心对比、干净消融、公平调优、规模/块长敏感性，以及 IR-ORAM、AB-ORAM、Freecursive、ρ 四类组合的带宽分析，提供原始记录、统计、论文表图及复现说明。

本轮用户明确只要求带宽优化证据，暂不要求实测加速比。因此应用层通信直接统计执行中的序列化请求和回复，包括认证、递归、所有 scheduled/neutral service 和最终 ACK；不要求先移植 socket。进程内传输不产生 TCP/TLS 流量，结果不称网络链路字节或延迟实测。
